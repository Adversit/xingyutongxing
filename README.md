# 星屿同行 · 写给明天的信

原创精灵收集与回合制冒险小游戏。像素主角沿着岛上的道路旅行，结识伙伴，并完成一个关于记忆、告别与继续同行的故事。

**公开游玩：** https://starfall-creature-isles.dingikang.chatgpt.site  
**独立仓库：** https://github.com/Adversit/xingyutongxing

## 2.0 可玩内容

- **六张可行走地图**：岸灯镇、萤叶林、琉璃湾、熔光岭、观星原、星潮核心，每张 40 × 28 格。可跟随像素主角移动的镜头，道路与支路、桥梁、河流、房屋、花田、集市、矿车、灯塔、星台和区域出口。
- WASD / 方向键移动，E / 空格与附近地标互动，手机方向键支持按住连续走；房屋、树林、矿石和水域有碰撞。NPC、采集点、商店、恢复站、守望者与隐藏路线有真实用途。野外每走 8 格推进一次探索，连续走 4 格草丛触发相遇；保留群岛航图与便捷行动。
- **六章完整主线、十四篇手记、两种结局**：逐步发现四座灯塔熄灭的原因，走进守灯人溯与暮星龙的故事。三相核心有雨、晴热、微风三个阶段；完成结局与回信后可捕捉暮星龙。已完成章节可回看，剧情赠礼只能领取一次。
- **24 种原创精灵、48 种招式**（含保底攻击），6 条进化路线。三位初始伙伴、6 人同行队伍、最多 100 位伙伴、最高 25 级；昵称、性格、成长专精与羁绊。
- 每位精灵学会 6 招，可配置 4 招，调整不恢复 PP。8 种元素与素属性，速度先手、同属性加成、天气、状态、暴击、轮换、吸血、反伤、破防、优先权、全队治疗与天气技能。
- **伙伴养成**：6 种具有实际效果的装备、3 种按属性区分喜好的点心、营地照料与心情、羁绊 30 / 60 / 90 的伙伴心声、每战一次的同行共鸣。装备更换会归还旧物，照料有探索冷却，心声奖励不能重复领取。
- **育幼篮**：4 组领养委托，最多同时照料 3 枚蛋，12 次野外探索孵化。第一章赠送花铃鹿之卵。新伙伴从 4 级、15 羁绊开始同行。
- 动态捕捉概率、昼夜与天气栖息地、采集与制作、商店、7 项研究记录、伙伴属性解锁隐藏路线、免费恢复和倒下救援。
- 本机自动存档、最近有效备份、JSON 导入导出。保留原 v1 存储键，自动迁移旧队伍、等级、徽记、物资、招式次数与进行中的战斗；旧旅人可补读主线。
- 探索/战斗两套 CC0 音乐、后台静音、减少动态效果设置；保留明确标注的无限物资测试模式。

## 运行

这是完整静态网站，无运行时依赖。需要 Python 3 与 Node.js 20+（测试）。

```sh
npm start        # http://localhost:8080
npm run check   # JavaScript 语法检查
npm test        # 规则、地图、存档与通关模拟
```

也可用任意静态 HTTP 服务器直接托管 `dist/`。请通过 HTTP 访问，ES Modules 不能直接从本机文件协议加载。

进度保存在当前浏览器，不提供云存档或多人联机；跨设备时请使用游戏内导出/导入。

## 验证

23 项自动化规则测试覆盖属性/天气、捕捉、资源消耗、进化、配招、装备、照料冷却、孵蛋、羁绊共鸣、剧情防重复领取、旧存档迁移、确定性战斗续接，以及六张地图从出生点到所有地标/草丛的可达性。

三个初始伙伴均在正常资源规则下完成四座灯塔、三阶段核心、六章主线与通关后暮星龙解锁，覆盖两种结局。固定种子到四座灯塔分别为 26 / 15 / 14 场战斗；这不是玩家试玩时长。

实际 DOM 交互验证了键盘/指针移动、邻近 NPC、主线选择、航图传送、营地照料、孵蛋、24 项图鉴、配方、装备、点心、剧情回顾、捕捉与本机保存。六张地图渲染图及精灵原图已检查。当前环境未提供受支持的浏览器预览，尚未完成真实桌面/手机视觉与音频试玩。

## 代码结构

- `dist/data.mjs`：精灵、招式、区域与物品数据。
- `dist/content.mjs`：六章剧情、结局、装备、点心和育幼委托。
- `dist/world.mjs`：地形、道路、地标与碰撞；与测试共享。
- `dist/world-view.mjs`：SVG 像素场景、主角与跟随镜头。
- `dist/game.mjs`：纯规则引擎、战斗、养成、剧情与存档迁移。
- `dist/app.mjs` / `dist/style.css`：界面、交互、音乐和响应式布局。
- `dist/assets/`：精灵原画、群岛总览与完整音乐文件。
- `dist/credits.html`：美术、音乐与玩法参考署名。

精灵与群岛总览使用 OpenAI 图像生成工具原创制作，可行走地图和像素角色由代码绘制。音乐为 CC0，来源与转码说明见游戏内制作说明。玩法参考宝可梦、Monster Sanctuary 与 Cassette Beasts 的公开资料，使用原创角色、叙事、规则与素材。
